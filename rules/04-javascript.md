# 🟨 Стандарты разработки на JavaScript (ES6+)

---

## 1. Модульная система и область видимости

- **Только ES-модули:** Используйте стандартные `import` и `export`.
- **Запрет глобального скоупа:** Запрещено привязывать свойства и функции к `window.*` или `globalThis.*`.
- **Переменные:**
  - `const` — по умолчанию для всех объявлений.
  - `let` — исключительно тогда, когда значение переменной действительно переназначается.
  - `var` — категорически запрещён.

---

## 2. Операции сравнения и типы

- **Строгое равенство:** Всегда используйте `===` и `!==`.
- **Запрет нестрогого сравнения:** Операторы `==` и `!=` запрещены во избежание неявного приведения типов.
- **Опциональная цепочка и nullish coalescing:** Активно используйте `obj?.prop` и `val ?? defaultValue`.

---

## 3. Асинхронность и обработка ошибок

- **Async / Await:** Предпочитайте синтаксис `async/await` цепочкам `.then()`.
- **Неотловленные промисы:** Вызовы без `await` допускаются только для фоновых задач при обязательном наличии `.catch(err => logger.error(err))`.
- **Изоляция сбоев:** Асинхронные обработчики событий DOM должны оборачиваться в `try / catch`.

---

## 4. Ограничения размеров и сложность

- **Функция > 40 строк** — сигнал к декомпозиции.
- **Обработчики событий (`handle*`) > 80 строк** — запрещены. Обработчик должен лишь извлекать параметры из события и делегировать выполнение сервисному слою.

---

## 5. Работа с DOM и шаблонизация

- **Запрет небезопасного HTML:**
  - Запрещена генерация больших фрагментов разметки через `element.innerHTML = '<div>...</div>'`.
  - Для динамических элементов используйте HTML `<template>` теги либо `document.createElement()`.
  - Допустима интерполяция в `innerHTML` только для простых скалярных значений после санитизации.
- **Кэширование DOM-запросов:**
  - Запрещены повторяющиеся вызовы `document.getElementById` или `document.querySelector` внутри циклов и в колбэках `requestAnimationFrame`.
  - Кэшируйте ссылки на DOM-элементы при инициализации модуля/компонента.

---

## 6. Константы и конфигурации

- **Именование:** `SCREAMING_SNAKE_CASE` для констант модуля.
- **Защита от мутаций:** Используйте `Object.freeze()` для экспортируемых объектов конфигураций и словарей перечислений.
- **Документирование:** Сопровождайте функции JSDoc-комментариями с описанием параметров и возвращаемых типов:
  ```javascript
  /**
   * Вычисляет итоговый размер буфера.
   * @param {number} baseSizeMb - Базовый размер в МБ.
   * @param {number} multiplier - Коэффициент масштабирования.
   * @returns {number} Размер в байтах.
   */
  ```
